Карта типов по месяцам

Каждая точка это муниципалитет, цвет показывает его тип в выбранном месяце. Колесо мыши приближает, перетаскивание двигает карту. Нажми на точку, чтобы открыть карточку муниципалитета, или на тип в легенде, чтобы выделить его.

Типы локальных экономик

Полосы показывают, во сколько раз показатель типа отличается от среднего по всем муниципалитетам: вправо от черты значит выше среднего, влево ниже.

Как типы меняются во времени

Число муниципалитетов каждого типа по месяцам. Наведи на график, чтобы увидеть значения; нажми, чтобы показать этот месяц на карте.

Переходы между типами за месяц

В строке указан тип в текущем месяце, в столбце тип в следующем. Значение показывает долю муниципалитетов, совершивших такой переход, в процентах.

Как это посчитано

    Сравнение методов по индексам качества

    Среднее по 24 месяцам. SW, CH, S_Dbw считаются по признакам; AVI, AVU, MQ, Q считаются по сети. Больше лучше: SW, CH, AVI, MQ, Q. Меньше лучше: S_Dbw, AVU.
