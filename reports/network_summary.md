## Лаговая корреляция: на каком сдвиге достигается сходство (k=10)

|                                                |   значение |
|:-----------------------------------------------|-----------:|
| доля рёбер с наибольшей корреляцией без сдвига |      0.594 |

| со сдвигом на 2 месяца и больше                |      0.216 |
| средняя корреляция на рёбрах без сдвига        |      0.3   |
| средняя наибольшая корреляция по сдвигам       |      0.496 |
